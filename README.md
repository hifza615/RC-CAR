# RC-CA# 🚗 Arduino-Based Bluetooth Controlled RC Car

A 2WD Remote-Controlled Car built using Arduino and Bluetooth technology. The car can be controlled wirelessly through a smartphone using an HC-05 Bluetooth module.

## 📌 Project Overview

This project demonstrates the practical application of Arduino programming, electronics, and wireless communication. The car receives commands from a smartphone through Bluetooth and moves according to the user's instructions.

## 🎯 Project Objectives

- To build a functional 2WD remote-controlled car.
- To understand Arduino-based motor control.
- To implement wireless communication using Bluetooth.
- To apply programming and electronics concepts in a practical project.

## 🛠️ Components Used

- Arduino UNO
- 2WD Robot Car Chassis
- DC Gear Motors
- L298N Motor Driver
- HC-05 Bluetooth Module
- Battery Pack and Battery Holder
- Jumper Wires
- Smartphone with a compatible Bluetooth controller app

## ⚙️ Working Principle

1. The smartphone sends movement commands through Bluetooth.
2. The HC-05 Bluetooth module receives the commands.
3. The Arduino UNO processes the incoming commands.
4. The Arduino controls the L298N motor driver.
5. The motor driver operates the DC motors to move the car forward, backward, left, or right.

## 💻 Technologies Used

## 🚀 Project Features

- Wireless smartphone control
- Forward and backward movement

## 📊 Project Outcome

The project demonstrates how Arduino, Bluetooth communication, and a motor driver can work together to control a small robotic vehicle wirelessly.
